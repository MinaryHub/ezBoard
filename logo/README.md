# ezBoard 로고 / Logo

말풍선 모양의 구리 배선 안에 납땜 패드 세 개("입력 중…")가 있는 마크입니다. "AI와 대화하며 회로를 만든다"는 뜻이고, 위쪽 패드는 로봇 안테나처럼 보여 AI를 떠올리게 합니다. 글자는 배선처럼 굵기가 일정한 손글씨 레터링이며, 마지막 d는 패드로 끝납니다.

The mark is a chat bubble drawn as a copper PCB trace with three solder pads inside like a "typing…" indicator. The wordmark is monoline trace-style lettering whose "d" ends in a pad.

| 파일 | 용도 |
|---|---|
| `mark.svg` | 앱 아이콘 (정사각형) / App icon |
| `mark-foreground.svg` | 안드로이드 적응형 아이콘 전경 (배경색 #0B6B45) |
| `logo-dark.svg`, `logo-dark-transparent.svg` | 어두운 배경용 가로 로고 |
| `logo-light.svg`, `logo-light-transparent.svg` | 밝은 배경용 가로 로고 |
| `wordmark-dark.svg`, `wordmark-light.svg` | 글자만 |
| `png/` | PNG 버전 |
