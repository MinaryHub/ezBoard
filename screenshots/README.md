# Store listing images / 앱 등록용 이미지

English is the primary set (this folder). Korean versions are in [`ko/`](ko/) with the same structure.
영어가 기본 세트이고, 한국어는 같은 구조로 [`ko/`](ko/) 폴더에 있습니다.

Regenerate / 다시 만들기: `npm run screenshots`

| Path | Store | Size |
|---|---|---|
| `desktop-2880x1800/` | Mac App Store (16:10) | 2880×1800 |
| `desktop-1920x1080/` | Microsoft Store, Linux (Snap Store, Flathub) | 1920×1080 |
| `android-phone-1080x1920/` | Google Play — phone screenshots | 1080×1920 |
| `play-feature-graphic-1024x500.png` | Google Play — feature graphic | 1024×500 |
| `app-icon-512.png` | Google Play — app icon | 512×512 |
